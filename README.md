# HW3 · Web 课程练习

使用 PHP、PDO 和 MySQL 实现学生信息录入与列表展示的课程练习。

## 代码内容

- 表单接收姓名与性别
- 校验非空输入
- 使用 PDO 预处理语句写入 `student` 表
- 按 ID 倒序读取并展示学生记录
- 提交后重定向，显示成功或输入为空的提示

## 文件

| 文件 | 内容 |
| --- | --- |
| `sqll.php` | PHP 页面、表单处理及数据库读写 |
| `1.png`、`2.png` | 作业附图 |

## 运行前准备

需要 PHP（启用 PDO MySQL 驱动）和 MySQL。按代码配置本地数据库，准备 `student` 表及 `id`、`realname`、`gender` 字段，再通过 PHP 服务器访问 `sqll.php`。

当前仓库未包含数据库初始化脚本；本次文档整理未执行数据库连接测试。数据库连接设置位于代码中，后续可改为本地环境变量配置。

## 项目边界

这是独立的 Web 课程练习，不与其他 Laravel 作业或业务项目合并。当前范围为录入和列表展示。
